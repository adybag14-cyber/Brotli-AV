ASM-first full research BAV vs full C# port
==========================================

ASM design (ports/asm):
  - NASM Win64 kernels: CRC32, MTF, RLE0, transpose/untranspose, sub/xor delta
  - C orchestration: auto candidate search (backends + research paths + BWT)
  - Backends: zlib deflate, zstd-22, brotli-11 (no LZMA; no token dictionary yet)

C# design (ports/csharp):
  - Full managed port with deflate + zstd + xz/lzma + brotli + token path

Results (method=auto, core corpus, lossless round-trips OK for both):
